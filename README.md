# 6p-go

`6p-go` is a small command-line client and Go package for uploading text or
supported image data to a compatible 6paster service. The command reads a file
or standard input and prints the resulting paste URL.

The input is sent to the configured remote paste service. Avoid uploading
secrets or sensitive data unless you trust that service.
